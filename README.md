# api-setup-practice

## 概要

COACHTECH 教材 Tutorial 11-1「API開発環境の構築と疎通確認」で作成した成果物です。
API開発環境の構築を行なった。

## 使用技術

- PHP 8.x
- Laravel 10.x
- REST API（JSONレスポンス）
- Postman（動作確認）

## 学んだこと

- laravelのAPIルートの書き方
- Postmanの基本的な使い方
- 基本的な書き方、使い方を理解を学んだが、深く理解していないという自覚があるため、もう少し教材を読み込む必要がある。

## 動作確認

Postmanで(http://localhost/api/hello)を入力し、レスポンスを確認した。
